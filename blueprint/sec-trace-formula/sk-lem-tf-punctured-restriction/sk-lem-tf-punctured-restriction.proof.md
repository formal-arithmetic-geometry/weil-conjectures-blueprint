The map factors as restriction to $R\Gamma(Y,M|_Y)$, then to the
stalk $M_s=R\Gamma(Z_{(s)}-Y,i_!E)$, given by the stalk formula, and
then to the displayed target. All these maps are restrictions from
the same complex, so the composite is the given map.
If $s\ne z$, Lemma [sk-lem-tf-transverse-boundary] makes the middle
composite zero. If $s=z$, the intermediate object $M_z$ is zero.
