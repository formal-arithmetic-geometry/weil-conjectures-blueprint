*The definition is well formed.* $S^{-1}P$ with the operations above is a commutative ring and $a\mapsto a/1$ a ring homomorphism (Stacks Project, Section 00CM); composed with the structure map $R\to P$ it makes $S^{-1}P$ an $R$-algebra. The condition is an existence statement over triples $(P,S,D\cong S^{-1}P)$, no choice is made, and it depends only on the isomorphism class of $D$ as an $R$-algebra (compose the given isomorphism with an $R$-algebra isomorphism $D'\cong D$). So 'essentially smooth' is a property of the ring map $R\to D$.
