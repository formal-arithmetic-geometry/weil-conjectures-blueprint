This is [sk-thm-curve-package], proved in [sec-curve-estimates]. For a smooth
proper connected curve and $n$ invertible in $k$, the Kummer sequence and the
Jacobian ([sec-picard-framework]) compute $H^q(C,\mu_n)$. For $p$-primary
coefficients one uses the Artin–Schreier sequence instead. The case of general
torsion sheaves is reduced to these cases by normalization, removal of finitely
many points and a finite étale cover of degree prime to the torsion order.
