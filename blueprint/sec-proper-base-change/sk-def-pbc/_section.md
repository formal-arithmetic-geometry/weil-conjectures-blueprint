*Definition (sketch).*

For a proper morphism $f:X\to Y$, write
$\mathrm{PBC}(f)$ if the exchange morphism
$\Ex_{\square,F}$ is an isomorphism in $\Dplus$ for every base
change and every torsion sheaf $F$ on $X_{\Et}$.
