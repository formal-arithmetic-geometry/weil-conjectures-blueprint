*The definition is well formed.* $S^{-1}P$ with the operations above is a commutative ring and $a\mapsto a/1$ a ring homomorphism (Stacks Section 00CM); composed with the structure map $R\to P$ it makes $S^{-1}P$ an $R$-algebra. 'Smooth $R$-algebra' is `Algebra.Smooth` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Smooth/Basic.lean)) for the structure map $R\to P$. The condition is an existence statement over triples $(P,S,D\cong S^{-1}P)$, no choice is made, and it depends only on the isomorphism class of $D$ as an $R$-algebra (compose the given isomorphism with an $R$-algebra isomorphism $D'\cong D$). So 'essentially smooth' is a property of the ring map $R\to D$.

*Remark (a): smooth and étale maps are essentially smooth.* If $R\to D$ is smooth `Algebra.Smooth` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Smooth/Basic.lean)), take $P=D$ and $S=\{1\}$: the map $a\mapsto a/1$ is an $R$-algebra isomorphism $P\to\{1\}^{-1}P$ (it is onto since $a/1$ are all the fractions, and injective since $a/1=0$ means $1\cdot a=0$), so $D\cong\{1\}^{-1}D$. If $\operatorname{Spec}D\to\operatorname{Spec}R$ is étale `AlgebraicGeometry.Etale` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/Etale.lean)), then by `AlgebraicGeometry.HasRingHomProperty.Spec_iff` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/RingHomProperties.lean)) $D$ is a finitely presented $R$-algebra with $H_1(L_{D/R})=0$ and $\Omega_{D/R}=0$ `KaehlerDifferential` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Kaehler/Basic.lean)); the zero module is a finite projective $D$-module (a direct summand of $D^0$), so the three conditions (i)-(iii) of `Algebra.Smooth` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Smooth/Basic.lean)) hold and $R\to D$ is smooth (Stacks, remark after Definition 00U1: if $R\to S$ is smooth it is étale iff $\Omega_{S/R}=0$; conversely an étale map satisfies the definition of smooth with $\Omega=0$), hence essentially smooth by the first case. This is the sentence 'Since an étale ring map is certainly essentially smooth we win' of the proof of Lemma 07FH.

*Remark (b): for $D$ local one may take $S=P\setminus\mathfrak P$.* Let $D$ be local (a nonzero ring with a unique maximal ideal $\mathfrak m$, so $D\setminus\mathfrak m$ is the set of units) and $D\cong S^{-1}P$ with $P$ smooth over $R$; let $\iota:P\to D$ be the composite $R$-algebra map $a\mapsto a/1$ followed by the isomorphism, and $\mathfrak P=\iota^{-1}(\mathfrak m)$, a prime ideal of $P$ (the preimage of a prime ideal; proper since $1\notin\mathfrak m$), so $T=P\setminus\mathfrak P$ is multiplicative. (1) Every $t\in T$ has $\iota(t)\notin\mathfrak m$, so $\iota(t)$ is a unit. (2) Every $s\in S$ has $\iota(s)$ a unit (it is $s/1$, with inverse $1/s$), so $\iota(s)\notin\mathfrak m$, i.e. $S\subseteq T$. (3) Every element of $D$ is $\iota(a)\iota(s)^{-1}$ with $a\in P$, $s\in S\subseteq T$. (4) If $\iota(a)=0$ then $ua=0$ for some $u\in S\subseteq T$, by the equality rule of $S^{-1}P$. Define $\theta:P_{\mathfrak P}=T^{-1}P\to D$ `Localization.AtPrime, Ideal.ResidueField, Ideal.Fiber` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Localization/AtPrime/Basic.lean)) by $a/t\mapsto\iota(a)\iota(t)^{-1}$, which makes sense by (1). It is well defined: if $v(at'-a't)=0$ with $v\in T$, then $\iota(v)(\iota(a)\iota(t')-\iota(a')\iota(t))=0$ and $\iota(v),\iota(t),\iota(t')$ are units, so $\iota(a)\iota(t)^{-1}=\iota(a')\iota(t')^{-1}$. It is additive and multiplicative by the formulas for fractions, sends $a/1$ to $\iota(a)$, hence is a homomorphism of $R$-algebras. It is surjective by (3). It is injective: $\theta(a/t)=0$ gives $\iota(a)=0$, so $ua=0$ with $u\in T$ by (4), so $a/t=0$ in $T^{-1}P$. Hence $D\cong P_{\mathfrak P}=(P\setminus\mathfrak P)^{-1}P$ as $R$-algebras, with the same smooth $P$; i.e. the presentation can be chosen with $S=P\setminus\mathfrak P$. (Conversely every $P_{\mathfrak P}$ is local `Localization.AtPrime, Ideal.ResidueField, Ideal.Fiber` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Localization/AtPrime/Basic.lean)).)
