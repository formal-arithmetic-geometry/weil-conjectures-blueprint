Let C be an abelian category with a chosen derived category [def-weil-pbc-derived-categories], n any integer, and K any bounded below derived object. The canonical map Hⁿ(K)→Hⁿ(D⁺(Id)(K)) given by mapDerivedCategoryPlusHomologyFunctorIso for Id is Hⁿ of the inverse component of mapDerivedCategoryPlusIdIso at K.
