Let k be a field, Λ a commutative ring, X a scheme and r a prime. For an etale sheaf F of Λ-modules with r id_F = 0, if r is a unit in Γ(Spec k, top), F has invertible-order torsion relative to Spec k. If r is not a unit there, invertible-order torsion forces F to be zero. The coefficient condition is the one of [def-weil-pbc-eight-curve-assertions].
