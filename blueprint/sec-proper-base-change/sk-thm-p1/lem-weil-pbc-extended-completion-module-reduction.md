Let R and S be commutative rings, I a finitely generated ideal of R, and φ : R → S a ring homomorphism. Put J = IS, Â = lim R/I^k and B̂ = lim S/J^k. Assume S/J is a finitely generated R/I-module via the induced quotient homomorphism. Let ψ : Â → B̂ be a ring homomorphism such that for every k, x and r, if the kth coordinate of x is r modulo I^k then the kth coordinate of ψ(x) is φ(r) modulo J^k. Give B̂ the Â-module structure via ψ and put K = IÂ. Then B̂/KB̂ is a finitely generated Â/K-module via the quotient module action.
