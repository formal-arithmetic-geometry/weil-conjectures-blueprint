Set P = MvPolynomial (Fin n) R and give S its P-algebra structure using alpha. Transport the quotient action on J.Cotangent along e.symm. The identity e.symm(alpha(p)) = mk J p gives IsScalarTower P S J.Cotangent. Mathlib KaehlerDifferential.kerCotangentToTensor constructs the P-linear conormal map c and LinearMap.extendScalarsOfSurjective makes it S-linear without changing its underlying function. (`KaehlerDifferential` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Kaehler/Basic.lean))).

Use KaehlerDifferential.mvPolynomialBasis and its scalar extension b to identify S tensor Omega[P/R] with Fin n -> S via b.repr and Finsupp.linearEquivFunOnFinite. Set d = t composed with c. The definition of c on toCotangent, Basis.baseChange_repr_tmul, and mvPolynomialBasis_repr_apply give d(g mod J^2)(i) = alpha(pderiv i g). (`KaehlerDifferential.mvPolynomialBasis` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Kaehler/Polynomial.lean))).

P is formally smooth by the polynomial instance. Mathlib Algebra.FormallySmooth.kerCotangentToTensor_injective_iff h_alpha identifies injectivity of c with Subsingleton (H1Cotangent R S), directly using presentation independence rather than the project Jacobi-Zariski quotient sequence. Mathlib KaehlerDifferential.exact_kerCotangentToTensor_mapBaseChange and mapBaseChange_surjective give surjectivity of c iff Subsingleton Omega[S/R]: in the forward direction every differential is w(c(a)) = 0; in the reverse direction w(x) = 0 so exactness gives a preimage of x under c. (`Algebra.instFormallySmoothMvPolynomial` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Smooth/Basic.lean)), `Algebra.Smooth` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Smooth/Basic.lean)), `KaehlerDifferential` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Kaehler/Basic.lean))).

The finite presentation instance is supplied directly by n, alpha, h_alpha and h_fg. Apply HasRingHomProperty.Spec_iff, RingHom.etale_algebraMap, Algebra.etale_iff and Algebra.formallyEtale_iff. Since t is a linear equivalence, d is bijective iff c is bijective. Substitute the two preceding equivalences and rearrange the conjunction to conclude. (`AlgebraicGeometry.HasRingHomProperty.Spec_iff` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/RingHomProperties.lean)), `AlgebraicGeometry.Etale` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/Etale.lean))).
