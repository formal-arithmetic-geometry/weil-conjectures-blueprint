Let $R$ be a commutative ring, $n,c\ge0$ integers and $f_1,\dots,f_c\in R[x_1,\dots,x_n]$ `MvPolynomial, MvPolynomial.aeval, MvPolynomial.algHom_ext` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/Algebra/MvPolynomial/Basic.lean)); let $T=R[x_1,\dots,x_n]/(f_1,\dots,f_c)$, an $R$-algebra. One says that *$T=R[x_1,\dots,x_n]/(f_1,\dots,f_c)$ is a relative global complete intersection* (over $R$) if every nonempty fibre of $\operatorname{Spec}T\to\operatorname{Spec}R$ has dimension $n-c$: for every prime ideal $\mathfrak p\subset R$ whose fibre ring $T\otimes_R\kappa(\mathfrak p)$ `Localization.AtPrime, Ideal.ResidueField, Ideal.Fiber` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Localization/AtPrime/Basic.lean)) is nonzero, the Krull dimension `topologicalKrullDim` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/Topology/KrullDimension.lean)) of the topological space $\operatorname{Spec}(T\otimes_R\kappa(\mathfrak p))$ `AlgebraicGeometry.Spec` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Scheme.lean)) equals $n-c$. A ring map $R\to S$ is a *relative global complete intersection* if there are such $n,c,f_1,\dots,f_c$ with $T$ a relative global complete intersection and an isomorphism of $R$-algebras $S\cong T$ (equivalently, a surjective $R$-algebra homomorphism $R[x_1,\dots,x_n]\to S$ whose kernel is the ideal $(f_1,\dots,f_c)$: this is what the source calls a presentation $S=R[x_1,\dots,x_n]/(f_1,\dots,f_c)$). Remark, not part of the definition: $\operatorname{Spec}(T\otimes_R\kappa(\mathfrak p))$ is homeomorphic to the fibre of $\operatorname{Spec}T\to\operatorname{Spec}R$ over $\mathfrak p$, and the fibre ring is nonzero exactly when that fibre is nonempty, so the condition says that every nonempty fibre has dimension $n-c$; if $c>n$ it says that $T=0$.
