Apply the equational criterion `Module.Flat.iff_forall_isTrivialRelation, Module.IsTrivialRelation` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Flat/EquationalCriterion.lean)) to the target ring S as an R-module through ψ. It suffices to trivialize every finite relation ∑ₖ rₖ • xₖ = 0. (`Module.Flat, RingHom.Flat` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Flat/Basic.lean))).

By `CategoryTheory.Limits.Concrete.isColimit_exists_rep, CategoryTheory.Under.preservesColimitsOfShape_forget_of_isConnected, CommAlgCat.commAlgCatEquivUnder, CommRingCat.FilteredColimits.forget_preservesFilteredColimits` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/CategoryTheory/Limits/ConcreteCategory/Basic.lean)), choose stage representatives aₖ of each coefficient rₖ. Filteredness supplies an object j receiving morphisms from all of the finitely many representing objects, including the empty family. Transport aₖ to bₖ in Rⱼ. The coprojection equations give ιⱼ(bₖ) = rₖ. (`CategoryTheory.Limits.colimit` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/CategoryTheory/Limits/HasLimits.lean))).

Regard S as an Rⱼ-module through ψ ∘ ιⱼ. The relation ∑ₖ bₖ • xₖ = 0 is the original relation because ιⱼ(bₖ) = rₖ. This module is flat by hypothesis. The forward equational criterion gives a finite matrix cₖₜ in Rⱼ and elements yₜ in S with xₖ = ∑ₜ cₖₜ • yₜ and ∑ₖ bₖ cₖₜ = 0. (`Module.Flat.iff_forall_isTrivialRelation, Module.IsTrivialRelation` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Flat/EquationalCriterion.lean)), `Module.Flat, RingHom.Flat` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Flat/Basic.lean))).

Use the matrix ιⱼ(cₖₜ) over R and the same yₜ. Its action on S is unchanged by the definition of the composite map. Applying the ring homomorphism ιⱼ to ∑ₖ bₖ cₖₜ = 0 yields ∑ₖ rₖ ιⱼ(cₖₜ) = 0. This is a trivialization of the original relation. The backward equational criterion proves flatness. (`Module.Flat.iff_forall_isTrivialRelation, Module.IsTrivialRelation` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/RingTheory/Flat/EquationalCriterion.lean))).
