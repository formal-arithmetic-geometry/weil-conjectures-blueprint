The inclusion of W is an open immersion and has closed image, hence a closed immersion (IsClosedImmersion.of_isPreimmersion, ClosedImmersion.lean:65, using Opens.range_ι). It is therefore finite, and also etale. The same applies to j inverse image W, whose closedness follows by continuity. The base change q0 is finite etale; composition gives both claimed properties. (`AlgebraicGeometry.IsClosedImmersion.iff_isFinite_and_mono` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/Finite.lean)), `AlgebraicGeometry.Etale.of_comp, AlgebraicGeometry.Etale.etale_comp, instance [IsOpenImmersion f] : Etale f` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/Etale.lean)), `AlgebraicGeometry.IsFinite.instCompScheme` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/Finite.lean))).

The inverse-image open square is cartesian by `AlgebraicGeometry.isPullback_morphismRestrict` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Restrict.lean)). Paste it vertically with the given square by `CategoryTheory.IsPullback.paste_vert_iff` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/CategoryTheory/Limits/Shapes/Pullback/IsPullback/Basic.lean)). The resulting square has vertical maps precisely the two restricted projections. Apply the rank base-change equality in `AlgebraicGeometry.Scheme.Hom.isLocallyConstant_finrank, AlgebraicGeometry.Scheme.Hom.finrank_of_isPullback, AlgebraicGeometry.Scheme.Hom.isIso_iff_finrank_eq` ([Mathlib source](https://github.com/leanprover-community/mathlib4/blob/master/Mathlib/AlgebraicGeometry/Morphisms/FlatRank.lean)).
