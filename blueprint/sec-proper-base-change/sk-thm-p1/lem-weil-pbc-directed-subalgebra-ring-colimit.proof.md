The index category is the partially ordered set $\mathcal I$, which is nonempty and directed, hence a filtered category. Since $\mathcal I$ is directed, the subring generated by all $A\in\mathcal I$ is their union, so $R=\bigcup_{A\in\mathcal I}A$.

Let $T$ be a commutative ring and $(\varphi_A:A\to T)_{A\in\mathcal I}$ ring maps compatible with the inclusions, i.e. $\varphi_{A'}|_A=\varphi_A$ for $A\subseteq A'$. Define $\varphi:R\to T$ by $\varphi(x)=\varphi_A(x)$ for any $A\in\mathcal I$ containing $x$. This is well defined: if $x\in A$ and $x\in A'$, choose $A''\in\mathcal I$ containing $A$ and $A'$; then $\varphi_A(x)=\varphi_{A''}(x)=\varphi_{A'}(x)$. It is a ring homomorphism: for $x,y\in R$ choose a single $A\in\mathcal I$ containing both (directedness), and use that $\varphi_A$ is a ring map; $\varphi(1)=\varphi_A(1)=1$. By construction $\varphi|_A=\varphi_A$ for every $A\in\mathcal I$, i.e. $\varphi$ factors the cocone.

For uniqueness, let $\varphi'$ be another ring map with $\varphi'|_A=\varphi_A$ for all $A$. Every $x\in R$ lies in some $A\in\mathcal I$, so $\varphi'(x)=\varphi_A(x)=\varphi(x)$. Hence the inclusion cocone with vertex $R$ satisfies the universal property of a colimit.
