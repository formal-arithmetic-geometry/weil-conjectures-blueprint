Write $p_{2,!}$ as extension by zero along a compactification of $p_2$
composed with the direct image along the proper $\bar p_2$. On bounded constructible
$E$- or $\Qlb$-complexes, extension by zero commutes with arbitrary base change
([sk-def-sfb-open-base-change]) and proper direct images satisfy proper base
change ([sk-thm-sfb-proper-base-change]), which together give the
compact-support base change [sk-thm-sfb-shriek-base-change]; hence $g^*p_{2,!}\cong p'_{2,!}g_V^*$ on the
base-changed square. The integrand base changes by pullback, and
$g_V^*\mathcal K_\psi\cong\mathcal K'_\psi$ because the pairing base changes
and the lisse Artin–Schreier sheaf pulls back to the sheaf of the
base-changed function ([sk-def-kernel]); the shift commutes with pullback.
