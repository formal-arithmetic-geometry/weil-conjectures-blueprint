By [def-weil-pbc-scheme-conventions], a universal homeomorphism $u$ is a
morphism every base change of which is a homeomorphism of underlying
topological spaces. If $v$ is a base change of $u$, then every base change of
$v$ is, by associativity of fibre products, also a base change of $u$, hence
a homeomorphism; so $v$ is a universal homeomorphism.
