Let $k\subseteq k'$ be algebraically closed and let $C$ be a
curve over $k$. Then $C_{k'}$ is a
smooth separated curve over $k'$ of the same dimension, and
$C_{k'}$ is proper (resp. affine) if $C$ is proper (resp. affine).
