An *abelian variety* over $k$ is a smooth proper geometrically
connected $k$-group scheme. If $A$ is an abelian variety, $[n]$
denotes multiplication by the integer $n$, and $A[n]=\ker[n]$ for $n>0$.
An invertible sheaf $\mathcal L$ on $A$ is *symmetric* if
$[-1]^*\mathcal L\simeq\mathcal L$.
