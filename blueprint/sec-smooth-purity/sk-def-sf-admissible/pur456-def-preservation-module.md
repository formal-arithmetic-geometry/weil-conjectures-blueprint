For $T\in\{\mathcal O_E,E,\overline{\mathbf Q}_\ell\}$, the adjunction of Definition [pur456-def-adjoint-datum-module] preserves the finite-Tor constructible categories if $Rf_{!,T}(D^b_{ctf}(X_{\Proet},T))\subseteq D^b_{ctf}(Y_{\Proet},T)$ and $Rf^!_T(D^b_{ctf}(Y_{\Proet},T))\subseteq D^b_{ctf}(X_{\Proet},T)$, with the full subcategories of Definition [pur713-def-ctf-module]. Preservation of the bounded constructible categories themselves is part of the construction (Inputs [pur713-input-cons-preservation-module] and [pur713-input-proper-adjoint-module]); only finite Tor amplitude is a condition here.
