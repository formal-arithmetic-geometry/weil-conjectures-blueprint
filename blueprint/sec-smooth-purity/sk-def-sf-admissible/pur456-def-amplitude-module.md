For $T\in\{\mathcal O_E,E,\overline{\mathbf Q}_\ell\}$, the adjunction of Definition [pur456-def-adjoint-datum-module] has uniform constructible cohomological amplitude with bounds $c_f^-\leq c_f^+$ if for all integers $a\leq b$,
$Rf^!_T(D_c^{[a,b]}(Y_{\Proet},T))\subseteq D_c^{[a+c_f^-,b+c_f^+]}(X_{\Proet},T)$, with the subcategories of Definition [pur456-def-intervals-module], the bounds being uniform in the interval and the object.
