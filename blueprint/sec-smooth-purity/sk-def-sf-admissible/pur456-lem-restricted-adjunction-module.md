For $T\in\{\mathcal O_E,E,\overline{\mathbf Q}_\ell\}$, if the adjunction of Definition [pur456-def-adjoint-datum-module] preserves the finite-Tor constructible categories (Definition [pur456-def-preservation-module]), then it restricts to an adjunction $Rf_{!,T}|_{D^b_{ctf}(X_{\Proet},T)}\dashv Rf^!_T|_{D^b_{ctf}(Y_{\Proet},T)}$ with the unit and counit of Definition [pur456-def-adjoint-datum-module].
