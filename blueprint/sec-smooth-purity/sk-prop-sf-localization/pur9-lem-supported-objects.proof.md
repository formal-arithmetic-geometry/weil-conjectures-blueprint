In the triangle of Lemma [pur9-lem-open-closed-triangle] for $N$, the first vertex is $\mathrm D(j_{!,\mathcal O_E/\varpi^n})\mathrm D(j^*_{\mathcal O_E/\varpi^n})N\cong\mathrm D(j_{!,\mathcal O_E/\varpi^n})Lj^*_{\mathcal O_E/\varpi^n}N=0$ (Lemma “The finite-coefficient derived inverse image is levelwise” (`pur713-lem-finite-pull-levelwise`)), so the second map is an isomorphism.
