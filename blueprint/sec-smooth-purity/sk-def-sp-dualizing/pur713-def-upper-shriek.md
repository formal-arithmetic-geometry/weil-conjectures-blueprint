For $f:X\to Y$ with chosen compactification $c_f=(j_f,p_f)$ and the adjoint of Input “Finite-coefficient proper-adjoint input” (`pur713-input-proper-adjoint`, in [sk-def-sf-operations]) for $p_f$, define

$$
Rf^!_{\mathcal O_E/\varpi^n}:=\mathrm D(j^*_{f,\mathcal O_E/\varpi^n})\circ Rp^!_{f,\mathcal O_E/\varpi^n}:
D(Y_{\Proet},\mathcal O_E/\varpi^n)\longrightarrow D(X_{\Proet},\mathcal O_E/\varpi^n).
$$

It is a composite of two specified functors. It is not defined by transporting an étale adjoint, by applying an operation to a tower of finite reductions, or by deriving an underived exceptional inverse image. For an arbitrary compactification $d=(j,p)$ of $f$, write $R^!_d:=\mathrm D(j^*_{\mathcal O_E/\varpi^n})\circ Rp^!_{\mathcal O_E/\varpi^n}$; this is used only in comparison statements.
