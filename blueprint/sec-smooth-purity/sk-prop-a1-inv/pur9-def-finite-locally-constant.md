title = "Finite locally constant sheaves"
order = 2297

A sheaf $F$ of $\mathcal O_E/\pi_E^n$-modules on $W_{\Et}$ is finite locally constant if there is an étale covering $\{W_\alpha\to W\}$ such that each $F|_{W_\alpha}$ is isomorphic to the constant sheaf with value a finite $\mathcal O_E/\pi_E^n$-module; it has rank one if these modules can be chosen free of rank one.
