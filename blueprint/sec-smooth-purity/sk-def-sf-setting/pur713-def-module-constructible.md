For $T\in\{\mathcal O_E,E,\overline{\mathbf Q}_\ell\}$, an $\mathcal R_{X,T}$-module $M$ is constructible if there is a finite stratification $X=\coprod_s X_s$ by locally closed subschemes, with inclusions $i_s:X_s\to X$, such that each $i_{s,\mathbf Z}^{-1}M$ is locally finitely presented over $i_{s,\mathbf Z}^{-1}\mathcal R_{X,T}$ in the sense of Definition [pur713-def-local-presentation]. This is the restriction convention of the governing reference, §6. It does not extend scalars to $\mathcal R_{X_s,T}$; comparison with that other restriction is an additional input.
