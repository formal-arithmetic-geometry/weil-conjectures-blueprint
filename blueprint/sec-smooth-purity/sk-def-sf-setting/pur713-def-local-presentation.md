For $\mathcal R$ as in Definition [pur713-def-finite-presentation], an $\mathcal R$-module $M$ is locally finitely presented if there is a covering family $\{u_i:U_i\to X\}$ of $X_{\Proet}$ such that, for every $i$, the module $u^{-1}_{i,\mathbf Z}M$ is finitely presented over the ring object $u^{-1}_{i,\mathbf Z}\mathcal R$ of $\mathsf{Sh}(U_{i,\Proet},\mathsf{Ab})$. The ring and module structures on these inverse images are obtained by applying the strong monoidal functor $u^{-1}_{i,\mathbf Z}$ of Input “Monoidality of fixed-coefficient images” (`pur713-input-fixed-monoidal`) to the original multiplication, unit and action. Torsion is allowed.
