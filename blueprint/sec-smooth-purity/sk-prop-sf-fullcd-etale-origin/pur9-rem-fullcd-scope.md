Lemma [pur9-lem-fullcd-origin] concerns only objects $L\nu^*_{\overline X',\mathcal O_E/\varpi^n}M$ with $M$ an étale sheaf, and only base changes along morphisms of finite-type $k$-schemes, because Input “The qcqs direct-image comparison theorem” (`pur7710-input-qcqs-comparison`, see [sk-prop-sf-comp-coherence]) is stated for such schemes. The source node also asserted the bound for base change along every object $V\to Y$ of $Y_{\Proet}$; such $V$ need not be of finite type over $k$, and that assertion lies outside the present framework. Taking $e=\dim\overline X$ requires the inequality between fibre dimension and the dimension of $\overline X$, which is not recorded here. The lemma does not establish $\mathrm{FullCD}(p,\mathcal O_E/\varpi^n;2e)$ of Definition [pur456-def-fullcd] (compare Remark [pur456-rem-admissibility]).
