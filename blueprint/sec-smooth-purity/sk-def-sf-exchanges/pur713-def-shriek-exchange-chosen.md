Under Input [pur713-input-comparison], for the Cartesian square $\square$ define

$$
\operatorname{Ex}^{\circ}_{!,\square,\mathcal O_E/\varpi^n}:=(\theta_{c',\mathcal O_E/\varpi^n}Lg'^*_{\mathcal O_E/\varpi^n})\circ\operatorname{Ex}_{!,\square,\mathcal O_E/\varpi^n}:
Lg^*_{\mathcal O_E/\varpi^n}Rf_{!,\mathcal O_E/\varpi^n}\longrightarrow Rf'_{!,\mathcal O_E/\varpi^n}Lg'^*_{\mathcal O_E/\varpi^n},
$$

with $\operatorname{Ex}_{!,\square}$ of Definition [pur713-def-shriek-exchange] and $c'$ the base change of $c_f$ (Definition [pur713-def-base-changed-compactification]). It is invertible at $K$ if and only if $\operatorname{Ex}_{!,\square,K}$ is, because $\theta_{c'}$ is an isomorphism.
