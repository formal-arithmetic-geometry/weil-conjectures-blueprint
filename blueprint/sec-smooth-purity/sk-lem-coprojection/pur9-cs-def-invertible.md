An invertible object of $D(X_{\Proet},\mathcal O_E/\pi_E^n)$ is a triple $(L,L',e)$ consisting of objects $L,L'$ and an isomorphism $e:L\otimes^L_{\mathcal O_E/\pi_E^n}L'\xrightarrow{\sim}(\mathcal O_E/\pi_E^n)_X$. One says that $L$ is invertible if such $L',e$ exist. The same definition is made in $D(X_{\Et},\mathcal O_E/\pi_E^n)$.
