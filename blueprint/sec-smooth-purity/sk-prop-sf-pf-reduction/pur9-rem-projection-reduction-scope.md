The source node concluded that $\operatorname{PF}_{f,K,L}$ is invertible if and only if its reduction is. That inference needs $r_{!,f}$, $r^\otimes$ and $r^*$ to be isomorphisms; $r_{!,f}$ is not shown here to be invertible. Under the hypotheses of Lemma [pur9-lem-proet-projection-formula] at both levels, both projection maps are already isomorphisms, so Lemma [pur9-lem-projection-reduction] records only the compatibility of the specified maps.
