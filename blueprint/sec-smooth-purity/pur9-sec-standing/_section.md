The remaining subsections of this section prove smooth purity at the finite coefficient $\mathcal O_E/\varpi^n$ on the pro-étale sites, using the exceptional inverse image of Definition [pur713-def-upper-shriek], and then discuss the non-finite stages. This subsection fixes the compactifications and proper adjoints used from now on, and it collects, each in a separate environment, the properties of these functors that the purity argument uses but that are not proved in this manuscript. Each input is a hypothesis of every result whose proof cites it, directly or through a cited result. None of them is supplied by the governing reference `DerivedCategoryAndSixFunctorsChoice.tex`, except where stated.
