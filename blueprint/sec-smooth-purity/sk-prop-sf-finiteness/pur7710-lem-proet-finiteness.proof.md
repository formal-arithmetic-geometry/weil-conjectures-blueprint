By Lemma [pur7710-lem-constructible-equivalence], an object of $D^b_c(X_{\Proet},\mathcal O_E/\varpi^n)$ is isomorphic to $L\nu^*_{X,\mathcal O_E/\varpi^n}L$ with $L\in D^b_c(X_{\Et},\mathcal O_E/\varpi^n)$. A morphism of finite type between Noetherian schemes is quasi-compact and quasi-separated, so the map $\lambda_{f,L}$ of Definition “The canonical direct-image comparison” (`pur7710-def-direct-image-comparison`, see [sk-prop-sf-comp-coherence]) is an isomorphism by Input “The qcqs direct-image comparison theorem” (`pur7710-input-qcqs-comparison`, see [sk-prop-sf-comp-coherence]); it identifies $Rf_{*,\mathcal O_E/\varpi^n}L\nu^*_{X,\mathcal O_E/\varpi^n}L$ with $L\nu^*_{Y,\mathcal O_E/\varpi^n}Rf_{*,\Et,\mathcal O_E/\varpi^n}L$. The latter lies in $D^b_c(Y_{\Proet},\mathcal O_E/\varpi^n)$ by Lemmas [pur7710-lem-finite-type-finiteness] and [pur7710-lem-constructible-equivalence].
