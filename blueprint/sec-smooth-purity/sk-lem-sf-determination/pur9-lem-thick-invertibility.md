For $\alpha$ as in Lemma [pur9-lem-two-of-three] and a class $\mathscr S$ of objects of $\mathscr T$, if $\alpha_X$ is an isomorphism for every $X\in\mathscr S$, then it is an isomorphism for every object of the thick subcategory generated by $\mathscr S$ (Definition [pur9-def-thick]). In particular, if that thick subcategory is $\mathscr T$, then $\alpha$ is an isomorphism.
