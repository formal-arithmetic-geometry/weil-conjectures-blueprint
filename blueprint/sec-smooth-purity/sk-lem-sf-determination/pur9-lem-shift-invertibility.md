For a morphism $\alpha:\Phi\to\Psi$ of exact functors (Definition [pur9-def-exact-transformation]) and every object $X$, $\alpha_X$ is an isomorphism if and only if $\alpha_{X[1]}$ is, and likewise for $X[-1]$.
