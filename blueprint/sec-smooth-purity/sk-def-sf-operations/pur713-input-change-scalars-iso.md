If $\phi$ is an isomorphism of ring objects, there is a natural isomorphism $\operatorname{Ext}_\phi\cong\operatorname{Res}_{\phi^{-1}}$; in particular $\operatorname{Ext}_\phi$ is exact and is a quasi-inverse of $\operatorname{Res}_\phi$. Source: governing reference, §4.2 (established there).
