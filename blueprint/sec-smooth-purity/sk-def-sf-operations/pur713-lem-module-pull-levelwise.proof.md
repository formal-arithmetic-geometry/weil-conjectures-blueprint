By Lemma [pur713-lem-module-pull-exact], $f^*_T$ is exact, so it preserves quasi-isomorphisms and induces $\mathrm D(f^*_T)$. For a K-flat resolution $P\to M$, the map $f^*_TP\to f^*_TM$ is a quasi-isomorphism, natural in $M$; it identifies the value $f^*_TP$ of $Lf^*_T$ with $\mathrm D(f^*_T)M$. A levelwise exact functor preserves cohomological boundedness below. This is the statement of the governing reference, §8.2.
