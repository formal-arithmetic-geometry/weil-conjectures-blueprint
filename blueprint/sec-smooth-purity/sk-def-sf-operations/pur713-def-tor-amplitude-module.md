For $T\in\{\mathcal O_E,E,\overline{\mathbf Q}_\ell\}$, an object $K\in D(X_{\Proet},T)$ has Tor amplitude in $[u,v]$, with integers $u\leq v$, if $\mathcal H^r(K\otimes^L_{\mathcal R_{X,T}}M)=0$ for $r\notin[u,v]$ and every $\mathcal R_{X,T}$-module $M$ placed in degree zero, with the tensor product of Definition [pur713-def-tensor-module]. The interval is uniform in $M$. Finite Tor amplitude means the existence of such an interval.
