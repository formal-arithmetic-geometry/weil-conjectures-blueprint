Let $W$ be a scheme. A test object of $W_{\Proet}$ is a morphism $u_B:B\to W$ that factors through an affine open $V\subseteq W$, where $B=\varprojlim_iB_i$ is a cofiltered limit, with affine transition maps, of affine schemes $B_i$ étale and of finite presentation over $V$. Such a morphism is weakly étale, so $B$ is an object of $W_{\Proet}$. The restriction of $K\in D(W_{\Proet},\mathcal O_E/\pi_E^n)$ to a test object is $Lu^*_{B,\mathcal O_E/\pi_E^n}K\in D(B_{\Proet},\mathcal O_E/\pi_E^n)$, with constant coefficients $\mathcal O_E/\pi_E^n$ (Definition “Finite-coefficient derived inverse image” (`pur713-def-derived-pull`)).
