Flat base change for coherent cohomology is compatible with cup
products, and Kähler differentials commute with base change. The
residue trace $H^1(C_K,\omega_{C_K/K})\to K$ restricts to the residue
trace of $C$ on $H^1(C,\omega_{C/k})\otimes1$, because residues are
compatible with extension of the base field.
