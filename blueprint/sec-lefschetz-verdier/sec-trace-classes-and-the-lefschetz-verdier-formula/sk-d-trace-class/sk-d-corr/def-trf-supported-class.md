In the setting of [def-trf-correspondence-between-pairs], let
$P\in D(Z,A)$ and let $i:T\to Z$ be a separated finite-type morphism of
separated finite-type $k$-schemes, with compact-support direct image
$Ri_!$ as in the coefficient conventions. A *class supported on $i$*
with values in $P$ is an element of

$$
H_T^0(Z,P):=\operatorname{Hom}_{D(Z,A)}\bigl(Ri_!A_T,P\bigr),
$$

where $A_T$ is the constant sheaf. The map $i$ is part of the data of
the class: it need not be an immersion, and different specified maps
with the same image give different groups.
