*Complement.* The trace class of the definition is the Verdier trace class:
the mate of $u$ followed by the trace map of external duality
([def-trf-trace-class]). It agrees with the supported pairing
$\langle u,1_K\rangle_{\mathrm{LV}}$ by [lem-trf-trace-class-diagonal-pairing].
