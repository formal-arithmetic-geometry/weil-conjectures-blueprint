For $\Lambda\in\{\mathcal O_E,E,\overline{\mathbf Q}_\ell\}$ and $M_i\in D^b_{\mathrm{ctf}}(X_i,\Lambda)$, the Künneth map (8.3) is defined in the same way, as the adjoint transpose for $h^*\dashv Rh_*$ on $D^b_{\mathrm{ctf}}$ of the same morphism.
