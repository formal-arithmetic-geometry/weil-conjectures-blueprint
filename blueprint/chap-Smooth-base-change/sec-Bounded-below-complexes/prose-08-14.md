Theorem [theorem-smooth-base-change-classical-torsion] concerns a single
torsion sheaf, but its applications concern complexes. Smooth base change on
$D^b_{\mathrm{ctf}}$ (Theorem [theorem-smooth-base-change-all-admissible]) is reduced,
for integral coefficients, to complexes with finite coefficients, and the
Künneth formula (Section [sec-The-Kunneth-formula]) is a statement about
complexes. So we need smooth base change for complexes of torsion
sheaves, and bounded below complexes suffice, since objects of $D^b_{\mathrm{ctf}}$ are
bounded.
