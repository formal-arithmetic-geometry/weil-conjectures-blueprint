In (8.1), smooth base change assumes that $g$ is smooth and
allows any $f$ of finite type. Proper base change assumes that $f$ is
proper and allows any $g$. Smooth purity
(Section [chap-Smooth-purity]) gives a
third base change isomorphism $g'^*f^!\simeq f'^!g^*$, for the exceptional
inverse image, when $f$ is smooth and $g$ is arbitrary. Neither smooth nor
proper base change applies to the open immersion
$j:\mathbf G_m\hookrightarrow\mathbf A^1$ of the beginning of this section,
where base change along the immersion of the origin fails.
Theorem [theorem-smooth-base-change-all-admissible] does not apply
because the immersion of the origin is not smooth. Proper base change does
not apply because $j$ is not proper.
