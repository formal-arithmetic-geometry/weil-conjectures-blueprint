The vanishing of a local term when $K_{\bar y}=0$ is hard to see from the
definition through the trace morphism
(Definition [definition-trace-morphism]), so we first replace that
definition by a description familiar from topology. There the
intersection number of two submanifolds $\Gamma$ and $\Delta$ is computed
by restricting the Thom class of $\Gamma$ to $\Delta$. Since the Thom class is supported on $\Gamma$, the result is a class supported on $\Gamma\cap\Delta$.
Similarly, in our setting $\psi$ defines a class supported on the graph. A restriction
map $\rho$ takes it to cohomology of the diagonal supported at $y$, and
the local term is the evaluation of the result. Note that the map $\rho$ does not involve $\psi$. It therefore suffices to show that $\rho$ itself is zero when
$K_{\bar y}=0$ (Lemma [lemma-vanishing-local-term-zero-stalk]), and
then the vanishing holds for every $\psi$, invertible or not.
