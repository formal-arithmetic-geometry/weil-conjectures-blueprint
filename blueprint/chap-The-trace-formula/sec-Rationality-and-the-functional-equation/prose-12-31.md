For example, let $X_0=\mathbf A^1_{\mathbf F_q}$. Then
$\#X_0(\mathbf F_{q^m})=q^m$, so that $Z(X_0,T)=(1-qT)^{-1}$. On the
cohomological side, $H^i_c(X,\mathbf Q_\ell)$ vanishes except for $i=2$, and
$H^2_c(X,\mathbf Q_\ell)\simeq\mathbf Q_\ell(-1)$ is a line on which geometric
Frobenius acts by $q$. The only factor is therefore
$(1-qT)^{-1}$, as it should be.

For $X_0=\mathbf P^1_{\mathbf F_q}$ the cohomology is $\mathbf Q_\ell$ in degree
$0$ and $\mathbf Q_\ell(-1)$ in degree $2$, so $Z(\mathbf P^1,T)=1/((1-T)(1-qT))$.
This matches $\#\mathbf P^1(\mathbf F_{q^m})=1+q^m$. For a curve of positive genus the middle cohomology contributes as well, and for the running example a single point count determines it.
