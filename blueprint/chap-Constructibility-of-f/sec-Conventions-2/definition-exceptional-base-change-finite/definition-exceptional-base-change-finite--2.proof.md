If $g$ is an open immersion, so is $g'$, and $g^*\simeq g^!$, $g'^*\simeq g'^!$
(Proposition [proposition-composition-open-restriction-compactifications-f](2)).
Under these identifications (6.1) is the composition isomorphism
$g'^!f^!\simeq(fg')^!=(gf')^!\simeq f'^!g^!$ of the same proposition, whose
transpose is (6.2); hence it is an isomorphism.
