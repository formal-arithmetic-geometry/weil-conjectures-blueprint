The set $\cO_E$ is a subring of $E$ by the ultrametric inequality, so with the subspace
topology it is a commutative topological ring, and [def-sfb-continuous-map-condensed-ring]
applies. The inclusion $\cO_E\subseteq E$ is a continuous ring homomorphism. If
$\mathbf Q_\ell\to E$ is $\mathbf Q_\ell$-linear, it preserves absolute values (see the
proof of [def-sfb-padic-subfield-condensed-ring]). So it maps
$\mathbf Z_\ell=\{|x|\le1\}$ into $\cO_E$, and the corestriction
$\mathbf Z_\ell\to\cO_E$ is a continuous ring homomorphism. In both cases
[def-sfb-continuous-map-condensed-ring-map] applies.
