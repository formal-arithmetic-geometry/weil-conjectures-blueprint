By [lem-sfb-lc-weakly-etale], $\Spec LC(S,\Z)\to\Spec\Z$ is weakly étale, so
$u(S)$ is an object of $(\Spec\Z)_{\mathrm{proét}}$. The composite of a
locally constant function with a continuous map is again locally constant, so
$h\mapsto h\circ g$ is a well-defined ring map. The induced morphism of
spectra lies over $\Spec\Z$ because $\Spec\Z$ is terminal. Precomposition
respects identities and composites, and so does $\Spec$. Hence $u$ is a
functor.
