Since $\iota$ is an injective ring homomorphism, $|\cdot|_E$ is an absolute value on $E$.
So $E$ is a normed field, in particular a commutative topological ring, and
[def-sfb-continuous-map-condensed-ring] applies. If $\iota$ is $\mathbf Q_\ell$-linear,
then $|\iota(x)|=|x|$ for $x\in\mathbf Q_\ell$, because the absolute value of $\Qlb$
extends that of $\mathbf Q_\ell$. Hence $\mathbf Q_\ell\to E$ is an isometric ring
homomorphism. It is in particular continuous, so
[def-sfb-continuous-map-condensed-ring-map] applies.
