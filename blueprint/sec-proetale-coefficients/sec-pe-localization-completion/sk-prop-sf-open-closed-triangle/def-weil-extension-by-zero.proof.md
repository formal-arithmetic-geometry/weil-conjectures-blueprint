An open immersion is weakly étale, so composition with $j$ is a functor
$\ell\colon U_{\mathrm{proet}}\to\overline X_{\mathrm{proet}}$,
$(T\to U)\mapsto(T\to U\to\overline X)$, the localization functor. The left Kan extension
along $\ell^{\mathrm{op}}$ exists without further hypotheses because $j$ is a monomorphism.
For $V\in\overline X_{\mathrm{proet}}$ the indexing category of
$(\operatorname{Lan}_{\ell^{\mathrm{op}}}M)(V)$ consists of the $T\in U_{\mathrm{proet}}$ with
an $\overline X$-map $V\to T$. A factorization of $V\to\overline X$ through $U$ is unique if it
exists, since $j$ is a monomorphism. If it exists, $(V\to U,\mathrm{id})$ is a terminal object
of the indexing category, and the value is $M(V\to U)$. Otherwise the category is empty and
the value is $0$. This is $P_M(V)$, compatibly with restrictions. Sheafification exists on
$\overline X_{\mathrm{proet}}$ since $\mathcal A$ is Grothendieck abelian.
