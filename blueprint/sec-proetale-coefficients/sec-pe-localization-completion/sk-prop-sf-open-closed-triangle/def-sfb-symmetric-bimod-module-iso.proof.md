The two bimodules have the same underlying object and the same left action $\gamma_P$.
The right action of the bimodule attached to $M$ is $\gamma_P\beta_{P,\mathcal R}$
([lem-sfb-modobj-symmetric-bimodules]), and this equals the right action $\rho_P$
because $P$ is symmetric. So the identity is compatible with both actions.
