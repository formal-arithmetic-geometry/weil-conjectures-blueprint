For the canonical t-structure, $K\in D^{\ge a}$ if and only if $H^i(K)=0$ for all $i<a$,
and $K\in D^{\le b}$ if and only if $H^i(K)=0$ for all $i>b$
[def-weil-abstract-derived-category]. Bounded means lying in $D^{\ge a}\cap D^{\le b}$ for
some $a,b$. The condition on the cohomology sheaves is the same on both sides.
