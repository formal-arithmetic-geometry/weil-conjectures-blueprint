The small pro-étale sites are essentially small, and a Grothendieck abelian category is
cocomplete, so the pointwise left Kan extension along $b^{\mathrm{op}}$ exists. For the
same reason sheafification exists on $Z_{\mathrm{proét}}$ with values in $\mathcal A$.
