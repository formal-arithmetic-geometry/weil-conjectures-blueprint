Put $\varepsilon(w)=\chi(w)c^{-\deg w}$. If $w=gs^d$ with $g\in\pi_1(U)$,
then $\varepsilon(w)=\chi(g)$, and hence $\varepsilon$ has finite image
by Theorem [sk-p-real-rankone]. At a closed point $x$ the
eigenvalue is $\varepsilon(\operatorname{Frob}_x)c^{\deg(x)}$. The first factor has finite
order, hence complex absolute value one, so the eigenvalue has absolute
value $q_x^{\lambda_\iota(c)/2}$. Changing $s$ multiplies $c$ by a
value of $\chi$ on $\pi_1(U)$, which has finite order, and so it does not
change this number.
