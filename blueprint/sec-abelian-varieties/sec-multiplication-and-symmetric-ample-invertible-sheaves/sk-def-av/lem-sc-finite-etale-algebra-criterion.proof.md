Since $A$ is a finite-dimensional $k$-algebra, it is of finite
presentation over $k$, and it is flat over the field $k$. So
$\Spec A\to\Spec k$ is étale if and only if it is unramified, i.e. if
and only if the diagonal $\Delta:\Spec A\to\Spec(A\otimes_kA)$ is an
open immersion ([def-weil-pbc-scheme-conventions]).

*Unramified $\iff\Omega_{A/k}=0$.* The diagonal is the closed
immersion defined by the kernel $I$ of the multiplication map
$\mu:B:=A\otimes_kA\to A$, and $I/I^2\cong\Omega_{A/k}$ as
$A$-modules (the standard description of the module of differentials
via the diagonal, $a\,db\mapsto a\otimes b-ab\otimes1$). The ring $B$
is finite-dimensional over $k$, hence Artinian, so
$\Spec B$ is a finite discrete space and $B=\prod_{\mathfrak q}B_{\mathfrak q}$
over its finitely many primes. An open subscheme of $\Spec B$ is thus
a union of connected components, of the form $\Spec(B/(1-\varepsilon))$
for an idempotent $\varepsilon\in B$. Hence $\Delta$ is an open
immersion if and only if $I=(1-\varepsilon)$ for an idempotent
$\varepsilon$, i.e. if and only if $I$ is generated by an idempotent.
For the finitely generated ideal $I$ of the Noetherian ring $B$ this is
equivalent to $I=I^2$: if $I=(f)$ with $f^2=f$ then $I^2=I$; conversely
if $I=I\cdot I$, Nakayama's lemma (determinant trick) gives $f\in I$
with $(1-f)I=0$, so $f=f^2$ and $I=(f)$. Therefore $\Delta$ is an open
immersion if and only if $I/I^2=0$, i.e. if and only if
$\Omega_{A/k}=0$.

*$\Omega_{A/k}=0\iff A$ is a finite étale $k$-algebra.* The Artinian
ring $A$ is a finite product $A_1\times\dots\times A_r$ of local
Artinian $k$-algebras, and $\Omega_{A/k}=\bigoplus_j\Omega_{A_j/k}$.
If $L=k(\alpha)$ is a finite separable extension with minimal
polynomial $P$ of $\alpha$, then $\Omega_{L/k}$ is generated by
$d\alpha$ subject to $P'(\alpha)\,d\alpha=0$, and $P'(\alpha)\ne0$ by
separability, so $\Omega_{L/k}=0$ (every finite separable extension is
simple by the primitive element theorem). This proves "$\Leftarrow$".
Conversely, suppose $\Omega_{A_j/k}=0$ for a local factor $A_j$ with
maximal ideal $\mathfrak m$ and residue field $\kappa=A_j/\mathfrak m$.
The surjection $\Omega_{A_j/k}\to\Omega_{\kappa/k}$ shows
$\Omega_{\kappa/k}=0$; for a finite extension $\kappa/k$ this forces
$\kappa/k$ separable (if $\kappa/k$ were inseparable, choose an
intermediate field $k\subseteq F\subsetneq\kappa$ with
$\kappa=F(\beta)$, $\beta^p\in F$ and $\beta\notin F$, $p=\operatorname{char}k$;
then $\kappa\cong F[t]/(t^p-\beta^p)$ has $\Omega_{\kappa/F}=\kappa\,d\beta\ne0$,
a quotient of $\Omega_{\kappa/k}$). Write $\kappa=k(\bar\alpha)$ with
separable minimal polynomial $P$. Since $\mathfrak m$ is nilpotent and
$P'(\bar\alpha)\ne0$, Newton's iteration $a\mapsto a-P(a)P'(a)^{-1}$,
starting from any lift of $\bar\alpha$, reaches in finitely many steps
a root $a\in A_j$ of $P$ lifting $\bar\alpha$; then $k[a]\subseteq A_j$
is a field mapping isomorphically onto $\kappa$, so
$A_j=k[a]\oplus\mathfrak m$ as $k[a]$-modules. The map
$D:A_j\to\mathfrak m/\mathfrak m^2$, $c+x\mapsto x\bmod\mathfrak m^2$
($c\in k[a]$, $x\in\mathfrak m$) is a $k$-derivation: for
$b=c+x$, $b'=c'+y$ one has $bb'=cc'+(cy+c'x+xy)$ and
$D(bb')=cy+c'x=b\,D(b')+b'\,D(b)$ in $\mathfrak m/\mathfrak m^2$,
because $\mathfrak m$ annihilates $\mathfrak m/\mathfrak m^2$. It
factors through $\Omega_{A_j/k}=0$, so $D=0$, i.e.
$\mathfrak m=\mathfrak m^2$; by Nakayama's lemma $\mathfrak m=0$.
Hence $A_j=\kappa$ is a finite separable extension of $k$, and $A$ is a
finite étale $k$-algebra.

For the last assertion, a finite $k$-group scheme is
$G=\Spec\Gamma(G,\mathcal O_G)$ with $\Gamma(G,\mathcal O_G)$ a finite
$k$-algebra ([def-sc-group-scheme]), and its étaleness is by
definition that of $G\to\Spec k$.
