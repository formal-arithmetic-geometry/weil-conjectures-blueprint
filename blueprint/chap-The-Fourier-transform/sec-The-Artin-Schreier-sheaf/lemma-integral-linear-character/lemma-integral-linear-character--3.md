This normalization is bypassed by the Lean route: the relative Thom
input of [lemma-integral-linear-character--1] asserts only that a
natural isomorphism exists, without identifying it with the trace map.

For $\lambda=0$, the specified isomorphism is the trace map for compactly supported cohomology.
