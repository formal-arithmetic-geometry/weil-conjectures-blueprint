Let $\Lambda_n=\mathbf Z/\ell^n\mathbf Z$, $q:\mathbf P^1_S\to S$, and let
$h=c_1(\mathcal O_{\mathbf P^1_S}(1))\in H^2(\mathbf P^1_S,\Lambda_n(1))$ be the Kummer
Chern class. Then:

1. $(1,h):(\Lambda_n)_S\oplus(\Lambda_n)_S(-1)[-2]\to Rq_*(\Lambda_n)_{\mathbf P^1_S}$ is an
isomorphism in $D(S_{\mathrm{proét}},\Lambda_n)$, compatible with every base change
$S'\to S$;
2. the trace $\operatorname{Tr}_q:Rq_*(\Lambda_n)_{\mathbf P^1_S}(1)[2]\to(\Lambda_n)_S$,
defined as the projection onto the second summand of the twisted
decomposition, is compatible with base change and on every geometric fibre
sends $c_1(\mathcal O_{\mathbf P^1_{\bar s}}(1))$, equivalently the class of any
rational point, to $1$;
3. for the diagonal $\Delta\subset P\times_SP$ ($P=\mathbf P^1_S$) with cycle class
$\delta$ and projections $p_1,p_2$,
$\operatorname{Tr}_{p_i}\circ Rp_{i*}\delta=\mathrm{id}_{(\Lambda_n)_P}$ for $i=1,2$.
