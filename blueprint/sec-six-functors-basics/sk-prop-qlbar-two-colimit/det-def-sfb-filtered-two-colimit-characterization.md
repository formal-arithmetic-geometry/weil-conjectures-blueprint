In the situation of [det-def-sfb-filtered-two-colimit-model] (directed $I$, coherent normalized
cocone), let $\Phi\colon\mathcal C_\infty\to\mathcal D$ be the comparison functor. Then:

1. $\Phi$ is essentially surjective if and only if (Obj) holds;
2. $\Phi$ is full if and only if (Hom-surj) holds;
3. $\Phi$ is faithful if and only if (Hom-inj) holds.

Hence the cocone is a filtered 2-colimit ([det-def-sfb-filtered-two-colimit-conditions]) if and only
if $\Phi$ is an equivalence of categories.
