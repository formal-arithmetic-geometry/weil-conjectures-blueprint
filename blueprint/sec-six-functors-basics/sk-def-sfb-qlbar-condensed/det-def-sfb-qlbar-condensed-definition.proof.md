Let $a,b\in\underline{\Qlb}(S)$ with $a(S)\subseteq E$ and $b(S)\subseteq F$. The compositum $EF$ is
a finite subextension ([det-def-sfb-qlbar-condensed-subextensions]) and a subfield, so
$(a\pm b)(S)\subseteq EF$ and $(ab)(S)\subseteq EF$; the sums, differences and products of continuous
maps are continuous because $\Qlb$ is a topological ring. A constant map with value in
$\mathbf Q_\ell$ (in particular $0$ and $1$) lies in $\underline{\Qlb}(S)$ with $E=\mathbf Q_\ell$.
So $\underline{\Qlb}(S)$ is a subring of the commutative ring $C(S,\Qlb)$. For $u\colon S'\to S$,
$(a\circ u)(S')\subseteq a(S)\subseteq E$, so restriction preserves the subrings, and it is a ring
homomorphism because the operations are pointwise.
