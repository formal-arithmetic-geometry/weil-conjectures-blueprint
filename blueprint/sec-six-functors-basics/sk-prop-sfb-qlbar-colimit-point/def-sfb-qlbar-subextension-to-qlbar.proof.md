The composite $S\to E\subseteq\Qlb$ is continuous, because $E$ carries the subspace
topology. It takes values in the finite subextension $E$, so it is a section of
$\underline{\Qlb}$. The assignment is a ring homomorphism, since the operations are
pointwise, and it commutes with precomposition. So it is a morphism of sheaves of rings,
and by part 3 of [sk-def-sfb-ring-object] a morphism of ring objects. Both
$j_F\circ\iota_{E,F}$ and $j_E$ send $a$ to the same map $S\to\Qlb$, which gives the
compatibility.
