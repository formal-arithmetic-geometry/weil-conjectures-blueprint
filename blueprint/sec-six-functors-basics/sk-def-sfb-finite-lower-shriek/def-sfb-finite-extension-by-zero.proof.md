The left Kan extension exists without further hypotheses because $j$ is a monomorphism.
For $W\in X_{\mathrm{proét}}$ the indexing category of
$(\operatorname{Lan}_{\ell^{\mathrm{op}}}F)(W)$ consists of the $T\in U_{\mathrm{proét}}$
with an $X$-map $W\to T$. A factorization of $W\to X$ through $U$ is unique if it exists.
If it exists, $(W\to U,\mathrm{id})$ is a terminal object of the indexing category, and
the value is $F(W\to U)$. Otherwise the category is empty and the value is $0$.
Sheafification exists on $X_{\mathrm{proét}}$ since $\mathcal A$ is Grothendieck abelian.
