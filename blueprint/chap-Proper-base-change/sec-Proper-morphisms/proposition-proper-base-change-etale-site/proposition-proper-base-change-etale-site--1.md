Let $\Lambda$ be a commutative ring which is torsion as an additive group.
If $\mathrm{PBC}_\Lambda(\mathbf P^1_S\to S)$ holds for every scheme $S$, then
$\mathrm{PBC}_\Lambda(f)$ holds for every proper morphism of schemes $f$.
