This consequence is bypassed by the Lean proof, which proves integral
proper base change for bounded constructible complexes by finite-coefficient
proper base change and derived Nakayama.

In the setting of
Proposition [proposition-proper-base-change-complete-integral], if
$g^*Rp_*K$ and $g'^*K$ are derived complete, then the base
change map $g^*Rp_*K\to Rp'_*g'^*K$ is an isomorphism.
