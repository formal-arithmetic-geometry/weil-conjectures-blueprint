Now suppose that $g^*Rp_*K$ and $g'^*K$ are derived complete. Then the
first completion map is an isomorphism. The second is $Rp'_*$ applied
to the completion map of $g'^*K$, so it is an isomorphism as well. The
base change map is then a composite of isomorphisms.
