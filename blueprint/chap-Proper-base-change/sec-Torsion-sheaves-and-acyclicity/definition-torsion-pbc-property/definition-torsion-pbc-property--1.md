For a morphism $f:X\to Y$, write $\mathrm{PBC}_{\Lambda}(f)$ if the base change map
(4.3) is an isomorphism
for every base change
$g:Y'\to Y$ and every $K\in D^+(X_{\acute{e}t},\Lambda)$ with torsion
cohomology sheaves.
