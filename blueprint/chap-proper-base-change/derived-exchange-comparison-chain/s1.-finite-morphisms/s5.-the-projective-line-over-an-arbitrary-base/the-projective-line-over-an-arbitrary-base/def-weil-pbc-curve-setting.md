Let $k$ be algebraically closed, let $C$ be separated of finite type over $k$
with $\dim C\leq1$, and let $F\in\Ab(C_{\Et})$ be a torsion sheaf. A pair
$(C,F)$ of this form is a *curve coefficient pair*.
