1. For the projection $\mathbf A^d_Y\to Y$ and $K=\Lambda_Y$, the
   trace map is the trace map of affine space (10.7)
   with the corresponding coefficients, which on each geometric fibre
   sends the class of the origin to $1$.
2. For a finite étale morphism, where $d=0$, the trace map is
   summation over the fibres.
