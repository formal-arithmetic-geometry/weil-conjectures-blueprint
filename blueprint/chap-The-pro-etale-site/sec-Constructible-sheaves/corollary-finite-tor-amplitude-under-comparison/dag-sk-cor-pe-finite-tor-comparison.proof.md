1. Fix the qcqs scheme $X$ and discrete Noetherian ring $\Lambda$. By [dag-sk-thm-pe-constructible-comparison], write $E=\nu_X^*$ for the equivalence $D^b_c(X_{\Et},\Lambda)\simeq\Dbc(X,\Lambda)$. In particular $E$ is fully faithful and each bounded constructible pro-étale object is isomorphic to $E(K)$ for some bounded constructible étale object $K$. (uses [dag-sk-thm-pe-constructible-comparison])
2. For each $K\in D^b_c(X_{\Et},\Lambda)$ and each pair of integers $a\le b$, apply only the Tor-interval assertion of [dag-det-pe-finite-tor-comparison-noetherian]: $K$ has Tor amplitude in $[a,b]$ if and only if $E(K)$ does. Taking the existential quantifier over the same pairs $(a,b)$ shows that $K$ has finite Tor amplitude if and only if $E(K)$ does. Here the tests are against every module sheaf on the respective site, as in `def-kun-tor-amplitude` and `det-def-sfb-constructible-tor-amplitude`, not merely constructible test sheaves. (uses [dag-det-pe-finite-tor-comparison-noetherian], `def-kun-tor-amplitude`, `det-def-sfb-constructible-tor-amplitude`)
3. The full subcategories of finite-Tor objects therefore admit the restriction of $E$. The map on every Hom set is the same bijection as for $E$, so this restriction is fully faithful. For $L\in\Dctf(X,\Lambda)$, choose $K$ and an isomorphism $E(K)\cong L$ using [dag-sk-thm-pe-constructible-comparison]. If $L$ has Tor amplitude in $[a,b]$, so does $E(K)$: tensor the isomorphism with each module sheaf in degree zero and apply cohomology. The interval assertion of [dag-det-pe-finite-tor-comparison-noetherian] then gives that same interval for $K$. Thus $K\in D^b_{\mathrm{ctf}}(X_{\Et},\Lambda)$, proving essential surjectivity of the restriction. Equivalently, restrict a quasi-inverse of $E$; its unit and counit remain isomorphisms in these full subcategories. This constructs the restricted equivalence, whose inverse has exactly the direction displayed in the statement. (uses [dag-sk-thm-pe-constructible-comparison], [dag-det-pe-finite-tor-comparison-noetherian], `det-def-sfb-constructible-tor-amplitude`, `def-kun-tor-amplitude`)
4. Finally, every ideal $I$ of a finite commutative ring $A$ is a finite set and is generated by its own elements: $I\subseteq (I)$ since each element is a generator, while $(I)\subseteq I$ since $I$ is an ideal. Hence every ideal is finitely generated, so $A$ is Noetherian by `def-weil-pbc-noetherian-ring`. Give $A$ the discrete topology and specialize the equivalence just constructed. This applies in particular to every finite commutative $\ell$-primary ring, with no regularity assumption. (uses `def-weil-pbc-noetherian-ring`)
