1. Work in the universe Type u fixed by `def-weil-size-convention`. The source construction first forms the w-strict localization C = WStrictLocalization R. It carries its canonical commutative-ring and R-algebra structures, and the declarations WStrictLocalization.indEtale and WStrictLocalization.faithfullyFlat give Algebra.IndEtale R C and Module.FaithfullyFlat R C. Its instance WStrictLocalization.isWStrictlyLocalRing says that Spec C is w-local and every localization at a maximal ideal is strictly henselian, in the terminology of [dag-def-weil-pbc-w-local] and `def-weil-pbc-henselian-terminology`. The strict-henselian part is obtained in the source construction from the retraction criterion for faithfully flat etale covers `lem-weil-pbc-split-etale-covers-maximal-local-criterion`, with separable residue extensions supplied by `lem-trf-ind-etale-residue-separable`; hence this is exactly the w-strictly-local notion recorded in [dag-det-pe-wlocal-strict-contractible]. (uses [dag-def-weil-pbc-w-local], `def-weil-pbc-henselian-terminology`, `lem-trf-ind-etale-residue-separable`, `lem-weil-pbc-split-etale-covers-maximal-local-criterion`)
2. Now apply the source lemma exists_isWContractibleRing_of_isWStrictlyLocal to the w-strictly-local ring C. Let X = ConnectedComponents (PrimeSpectrum C), let pres := CompHaus.projectivePresentation (CompHaus.of X), let T := pres.p, and let i : T -> X be pres.f. The projectivity instance gives ExtremallyDisconnected T, while CompHaus.epi_iff_surjective pres.f gives Function.Surjective i. Thus T is an extremally disconnected compact Hausdorff totally disconnected space in the same universe.
3. Define D := WContractification.PullbackProfinite C T i. Its construction starts from the ring LocallyConstant T C: by [dag-lem-weil-pbc-locally-constant-prime-spectrum], Spec (LocallyConstant T C) is homeomorphic to T x Spec C, and the filtered presentation through finite discrete quotients is carried out in Type u using the colimit-flatness result `lem-weil-pbc-flat-colimit-presentation-same-universe`. Restricting to the closed graph of i uses the clopen-component intersection argument `lem-weil-pbc-quasicompact-components-clopen-intersection` and the spectrum-range theorem `lem-weil-pbc-restriction-spectrum-range`. Consequently the canonical C-algebra D is ind-Zariski (the ind-Zariski property is closed under the displayed composition in the source construction). (uses [dag-lem-weil-pbc-locally-constant-prime-spectrum], `lem-weil-pbc-flat-colimit-presentation-same-universe`, `lem-weil-pbc-quasicompact-components-clopen-intersection`, `lem-weil-pbc-restriction-spectrum-range`)
4. The theorem WContractification.PullbackProfinite.isPullback identifies Spec D with the fiber product T x_X Spec C. Therefore ConnectedComponents.wlocalSpace_of_isPullback supplies WLocalSpace (PrimeSpectrum D), and ConnectedComponents.preimage_closedPoints_eq_closedPoints_of_isPullback says that a closed point of Spec D maps to a closed point of Spec C. In particular D is w-local as required by [dag-def-weil-pbc-w-local]. (uses [dag-def-weil-pbc-w-local])
5. For a maximal ideal m of D, view m as a closed point y of Spec D. The closed-point equality from the pullback shows that projSpec y is a maximal point of Spec C. Since C is w-strictly local, C localized at the corresponding maximal ideal is strictly henselian. The ind-Zariski map C -> D is bijective on stalks by RingHom.IndZariski.bijectiveOnStalks, i.e. by `lem-weil-pbc-ind-zariski-bijective-on-stalks`; its local-ring isomorphism at m transfers the strictly henselian structure (including the henselian and separably closed-residue-field clauses of `def-weil-pbc-henselian-terminology`) to D_m. Hence D is w-strictly local. (uses `def-weil-pbc-henselian-terminology`, `lem-weil-pbc-ind-zariski-bijective-on-stalks`)
6. The same pullback square has the component-space homeomorphism ConnectedComponents.isHomeomorph_lift_of_isPullback, identifying ConnectedComponents (PrimeSpectrum D) with T. Since T is extremally disconnected, extremallyDisconnected_of_homeo transfers this property to the component space of Spec D. Together with the preceding w-strict-local conclusion, this is precisely IsWContractibleRing D in the sense of [dag-det-pe-wlocal-strict-contractible].
7. The source declaration WContractification.PullbackProfinite.faithfullyFlat C T i, using the surjectivity of i and the flatness of the ind-Zariski algebra, gives Module.FaithfullyFlat C D. Thus D is a commutative ring in Type u, is ind-Zariski and faithfully flat over C, and is w-contractible. The flatness input is exactly the filtered-colimit argument recorded in `lem-weil-pbc-flat-colimit-presentation-same-universe`. (uses `lem-weil-pbc-flat-colimit-presentation-same-universe`)
8. Finally equip D with the R-algebra structure obtained by composing R -> C -> D. The scalar-tower identity is the one used in the Lean proof. Algebra.IndEtale.trans applied to Algebra.IndEtale R C and the ind-Zariski (hence ind-etale) map C -> D yields Algebra.IndEtale R D, and Module.FaithfullyFlat.trans applied to the two faithfully flat maps yields Module.FaithfullyFlat R D. The IsWContractibleRing instance on D is unchanged. Hence D satisfies all clauses of the statement, with no nontriviality assumption and with all objects in Type u.
