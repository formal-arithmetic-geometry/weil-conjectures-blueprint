This relative cohomological dimension statement is bypassed by the Lean
proof of the main theorem. The current mainline uses explicit vanishing
bounds for étale higher direct images, and has no corresponding declaration
for $\operatorname{cd}_\ell(g)$ as defined in [definition-cohomological-dimension].

The morphism $g$ satisfies $\operatorname{cd}_\ell(g)<\infty$.
