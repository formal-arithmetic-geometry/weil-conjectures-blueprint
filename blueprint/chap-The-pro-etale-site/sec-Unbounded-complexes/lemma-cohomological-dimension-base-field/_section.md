If $k'$ is an algebraically closed field, then $\href{@definition-cohomological-dimension}{\operatorname{cd}_\ell(k')}=0$.
If $k'$ is a finite field, then $\href{@definition-cohomological-dimension}{\operatorname{cd}_\ell(k')}\le1$.
