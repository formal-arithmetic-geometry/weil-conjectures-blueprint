Applying the Milnor sequence (2.2) to the
tower of complexes $R\Gamma(X_{\mathrm{pro}\acute{e}t},F_n)$ and using the proposition, we
obtain for every $q$ a natural exact sequence

$$
0\longrightarrow R^1\varprojlim_nH^{q-1}(X_{\mathrm{pro}\acute{e}t},F_n)
\longrightarrow H^q(X_{\mathrm{pro}\acute{e}t},F)
\longrightarrow\varprojlim_nH^q(X_{\mathrm{pro}\acute{e}t},F_n)
\longrightarrow0.
\tag{2.11}
$$

The first term can be nonzero, because the transition maps between the
cohomology groups need not be surjective even if those between the
sheaves $F_n$ are. It vanishes if the groups
$H^{q-1}(X_{\mathrm{pro}\acute{e}t},F_n)$ satisfy the Mittag–Leffler condition. This
holds for instance if they are finite, since then descending chains of
images stabilize at each level.
