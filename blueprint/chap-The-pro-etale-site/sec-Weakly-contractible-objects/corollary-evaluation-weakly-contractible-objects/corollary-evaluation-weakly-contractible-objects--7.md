A morphism $f\colon A\to B$ of $\mathcal R$-module sheaves is an
isomorphism if and only if $f(W)\colon A(W)\to B(W)$ is bijective for
every affine weakly contractible $W$.

Likewise, a morphism $v\colon K\to L$ of complexes of
$\mathcal R$-module sheaves is a quasi-isomorphism if and only if
$v(W)\colon K(W)\to L(W)$ is a quasi-isomorphism for every such $W$.
No boundedness assumption is needed.
