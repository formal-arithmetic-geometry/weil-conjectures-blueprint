For a smooth-proper datum $\mathscr X=(X_0,d,X)$ and
$0\leq i\leq2d$, set

$$
D_i(\mathscr X)=
(-1)^{b_i(\mathscr X)}
[T^{b_i(\mathscr X)}]P_i(\mathscr X)(T)\in\mathbf Z.
$$

Since $b_i(\mathscr X)=\deg P_i(\mathscr X)$, this is a nonzero integer.
Once $\mathscr X$ is fixed, write it simply as $D_i$.
