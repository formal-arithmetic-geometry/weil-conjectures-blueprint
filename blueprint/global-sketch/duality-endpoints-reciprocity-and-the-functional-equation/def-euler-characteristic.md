For a smooth-proper datum $\mathscr X=(X_0,d,X)$, define

$$
\chi(\mathscr X)=\sum_{i=0}^{2d}(-1)^ib_i(\mathscr X).
$$

Once $\mathscr X$ is fixed, write this integer simply as $\chi$.
