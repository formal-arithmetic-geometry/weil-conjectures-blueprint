The image of $q$ is open, and it is closed because $q$ is proper, hence
universally closed. Since $D\hookrightarrow X$ is quasi-compact and
scheme-theoretically dense, $D$ is topologically dense, so the closed set
$q(Z)\supseteq D$ contains $\overline D=X$. Thus $q$ is a surjective open
immersion, i.e. an isomorphism.
