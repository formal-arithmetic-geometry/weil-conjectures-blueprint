The composite $C\to C_a\to B$ is $f$, so its kernel is $K$. If $c\in K$,
take $n=0$. Conversely, if $a^nc\in K$ then $f(a)^nf(c)=0$ in $B$, and since
$f(a)$ is a unit, $f(c)=0$. This proves the displayed equality. The class of
$c$ in $C/K$ is $a$-power torsion exactly when $a^nc\in K$ for some $n$, which
gives the description as an inverse image of $\Gamma_{(a)}(C/K)$.
