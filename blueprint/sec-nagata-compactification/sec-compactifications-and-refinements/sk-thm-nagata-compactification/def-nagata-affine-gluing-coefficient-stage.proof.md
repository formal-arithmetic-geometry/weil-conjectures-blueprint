The required coefficients exist because the $f_{aar}$ cover $U_a$, the
$f_{abq}$ cover $D(g_{bar})\subseteq U_a\cap U_b$, and the $f_{bcq}$ cover
$D(f_{abr}f_{acs})\subseteq U_b\cap U_c$, and every section over a basic
open $D(s)$ of the affine $U_a$ is a fraction $n/s^k$ with
$n\in\Gamma(S,U_a)$. There are finitely many charts, overlap elements and
coefficients, so each generating set is finite and every
$A^{\mathrm{coeff}}_a$ is a finitely generated $\mathbf Z$-algebra. One
round of this closure suffices: the gluing identities are imposed only
afterwards, by passing to a valid stage.
