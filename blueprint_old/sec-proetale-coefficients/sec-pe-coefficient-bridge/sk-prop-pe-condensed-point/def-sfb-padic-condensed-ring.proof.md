$\mathbf Q_\ell$ is a commutative topological ring, so
[def-sfb-continuous-map-condensed-ring] applies. The inclusion
$\mathbf Z_\ell\subseteq\mathbf Q_\ell$ is a ring homomorphism, and it is continuous
because $\mathbf Z_\ell$ carries the subspace topology. So
[def-sfb-continuous-map-condensed-ring-map] applies.
